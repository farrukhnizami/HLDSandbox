== Glossary

*Contents*

_The most important domain and technical terms that your stakeholders use
when discussing the system.
You can also see the glossary as source for translations if you work in
multi-language teams._

*Motivation*

_You should clearly define your terms, so that all stakeholders_

* have an identical understanding of these terms
* do not use synonyms and homonyms

*Form*

_A table with columns ++<++*Term*++>++ and ++<++*Definition*++>++.
Potentially more columns in case you need translations._

*Royal Mail FDS - Processing Sites: Worked Example*

[width="100%",cols="25%,75%",options="header",]
|===
|*Term* |*Definition*
|AWD |Authorised Working Directive - an employee's contracted standard working day; the baseline against which OT and SA are measured.
|Book Room |Site administrative function holding attendance and pay-related records; an authorised approver for OT timesheets.
|Console |Fixed terminal at a Processing Site capturing employee scan-on / scan-off events.
|DP |Royal Mail enterprise Data Platform deployed on GCP - the strategic landing zone for analytical data feeds; visualised primarily through Qlik.
|Duty |A defined scheduled role at a site, with associated work-area splits and rotation pattern.
|Duty Holder |The employee allocated to a duty for a given week of rotation.
|FDS |Front Line Demand and Supply - the Royal Mail platform for workforce planning across the front-line estate.
|JoinedUp |Third party SaaS platform used by RMG for requesting agency worker, also the destination for approved agency timesheets.
|MDS |Master Duty System - the system of record for duty masters and reference data.
|MoSCoW |Prioritisation taxonomy: Must-have, Should-have, Could-have, Won't-have.
|MVP |Minimum Viable Product - the smallest release delivering meaningful value.
|OT |Overtime - work performed beyond the AWD, requiring planning, approval and pay processing.
|PDA |Personal Digital Assistant - handheld device used by front-line staff for scan operations.
|Plan-vs-Scan |The reconciliation pattern comparing approved plans against PDA/Console scan data.
|Processing Site |Mail Centres, Hubs and Super Hubs in scope of this HLD.
|PSM |Processing Site Manager - primary daily user of FDS at a processing site.
|PSP |Royal Mail's payroll system
|Qlik Cloud |Royal Mail's strategic visualisation platform for operational and finance reporting.
|RCS |Resource Control System for reporting to the planned vs actual hours used by in a site for cost governance.
|SA |Schedule Attendance against pre-scheduled non-AWD shifts requiring approval and pay processing.
|Site Loan |The borrowing of an employee from another site to cover demand; supported via the attendance plan.
|WAM |Work Area Manager operational manager of a defined work area within a Processing Site.
|===
